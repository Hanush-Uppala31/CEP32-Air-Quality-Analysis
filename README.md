# CEP-32 Particulate Matter Analysis

Interactive GitHub Pages website for analyzing CPCB/data.gov.in particulate matter data.

## Included analyses
- Q1: Average PM2.5 and PM10 concentration
- Q2: Filter by monitoring station and date
- Q3: Handle missing pollutant concentration values
- Q4: Group by region and season
- Q5: Trend visualization
- Original uploaded dataset

The site is a static HTML/CSS/JavaScript website and can be published directly with GitHub Pages.
