Dataset snapshot

The uploaded file contains 1 unique timestamp: 21 Sep 2026, 10:00. Because this file is a single real-time snapshot, a true multi-day or multi-month time trend cannot be derived from this file alone. Q5 therefore shows the available time point and clearly labels the limitation.

Data cleaning used for Q3: missing pollutant_min, pollutant_max and pollutant_avg values are filled with the median for the same pollutant_id. The original data is never overwritten.
